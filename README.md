# Ecommerce Sales Analytics Dashboard

## Project Overview
This project analyzes ecommerce sales data using SQL and Tableau to uncover business insights related to revenue trends, delivery performance, payment methods, and top-performing product categories.

## Tools Used
- SQL
- Tableau
- CSV Dataset

## Dashboard Features
- Revenue trend analysis
- Delivery performance tracking
- Order status analysis
- Payment method analysis
- Top product categories

## Key KPIs
- Total Revenue
- Total Orders
- Average Order Value
- Average Delivery Time

## Key Insights
- Most orders were delivered on time.
- Credit card was the most used payment method.
- Beauty and health categories generated highest sales.
- Revenue trends showed seasonal fluctuations.
